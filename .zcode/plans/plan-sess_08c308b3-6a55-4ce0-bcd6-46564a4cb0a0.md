## 目标

做一个 B 站网页版油猴脚本：**按住 → 进入长按倍速后，用 ↑/↓ 以 0.25x 为步长实时微调倍速**，下限 0.5x、上限 3.0x，松开 → 恢复正常倍速，调整结果记住、下次长按沿用。

## 界面行为规格

| 场景 | 行为 |
|---|---|
| 短按 →（<300ms） | 完全保持 B 站原生行为（+5s 快进），不受影响 |
| 按住 → ≥300ms | 进入长按倍速；若有记忆值则以记忆值播放（如 2.75x），否则沿用 B 站默认长按倍速（通常 3x） |
| 长按期间按 ↑ / ↓ | 倍速 +0.25x / −0.25x，夹在 [0.5x, 3.0x]；按住不放可连续调节（约 100ms 一步的节流）；屏幕显示当前倍速浮层 |
| 松开 → | 恢复长按前的普通倍速（B 站自身恢复 + 我们兜底），记忆值保存 |
| 在输入框内 / 按住 Ctrl、Shift、Alt 时 | 不生效，不干扰打字与浏览器快捷键 |

## 调研结论（已确认，作为设计依据）

- B 站长按 → 的机制：**300ms 定时器**后写入 `video.playbackRate` 和 `defaultPlaybackRate`；默认 3x（部分用户处于 A/B 实验组，默认 2x 或"智能"）；松开时恢复到长按前的值。短按 → 是 +5s 快进。
- 实验组用户**原生就有 ↑/↓ 切档**，但只在"智能/1.5x/2x/3x"四档间循环、280ms 节流——我们的脚本会接管 ↑/↓，把它替换成 0.25 步长的精细调节。
- ↑/↓ 默认行为：播放器聚焦时调音量 ±10%，未聚焦时滚动页面——长按期间我们都拦掉，避免误调音量/滚页。
- B 站键盘监听绑在 **window 冒泡阶段**；我们在 window **捕获阶段**（document-start 注册）拦截，可完全压制它。同类脚本（bilibili-tweaks 等）已验证此做法。
- `<video>` 在普通 video / 番剧 / 课程页均为 light DOM，`.bpx-player-video-wrap video` 可靠，无 shadow DOM；**换清晰度/换源时元素会被替换**，需要监听重建。课程页无长按倍速设置（固定 3x），但我们的功能仍可用。

## 实现要点

1. **按键层**：`window` 捕获阶段监听 keydown/keyup（document-start）。跟踪 `ArrowRight` 和 `Numpad6`；输入框聚焦、带修饰键、窗口失焦时复位；↑/↓ 的处理用 `preventDefault + stopImmediatePropagation` 拦在 B 站之前，keyup 也一并吞掉避免残留。
2. **长按判定**：→ keydown 起 300ms 定时器确认长按（与 B 站一致，避免破坏短按快进）；期间一旦按 ↑/↓ 也立即进入调节状态。
3. **倍速接管**：在 video 元素上重定义实例属性 `playbackRate` 的 setter——接管期间把**任何**写入（含 B 站 300ms 时写的值、实验组的档位切换）重定向为我们的目标值，不接管时透传。这样不会和 B 站互相"抢写"，也没有闪烁。同时监听 `ratechange` 记录长按前的基准倍速。
4. **松开兜底**：若 150ms 后倍速仍是我们改过的值（B 站未恢复，如播放器未聚焦场景），自动恢复基准倍速。
5. **元素重建**：选择器优先 `.bpx-player-video-wrap video`，回退 `.bpx-player-container video` → 全页 `video` 取可见面积最大者；MutationObserver + `emptied/loadedmetadata` 事件在切P/换清晰度后重新获取并打补丁。
6. **浮层**：自绘深色小胶囊显示"2.75x"（长按期间常显、松开约 400ms 后淡出）；期间隐藏 B 站自带倍速提示（其选择器在实施第一步实地确认），避免两个数字打架。
7. **设置**：`GM_registerMenuCommand` 菜单：开/关、步长（0.1/0.25/0.5 循环）、上限（1.5/2/2.5/3/4）、下限（0.25/0.5/0.75/1）、记住开关、浮层开关、清除记忆、恢复默认；值存 `GM_setValue`。脚本对 GM API 做特性检测并提供 localStorage 降级，便于本地测试页直接加载。
8. **健壮性**：防重复注入标记、`@noframes`、非视频页 no-op；所有选择器集中在一个常量区便于 B 站改版后维护。

## 实施步骤

1. **实地勘察**（浏览器自动化打开真实 B 站视频页）：确认 video 选择器与数量、B 站长按倍速提示元素的选择器与位置、本机是否处于原生 ↑/↓ 实验组、↑/↓ 默认行为（音量/滚页）；据此定稿选择器与浮层位置。
2. 编写脚本骨架（元数据、配置存储、菜单）。
3. 实现核心：video 获取/重建、按键状态机、playbackRate 接管、松开恢复。
4. 实现浮层与原生提示隐藏。
5. **验证**：
   - 用浏览器自动化把脚本注入真实 B 站视频页（等价于 Tampermonkey 注入），用 CDP 真实按键事件测：长按 → 后 ↑/↓ 步进、0.5x/3.0x 夹取、连续调节、松开恢复、音量不被改动、短按 +5s 快进不受影响、输入框内不触发、切P后仍生效。
   - 另用 `test/harness.html` 做离线回归。
   - 若自动化无法访问 B 站，退化为本地 harness + 人工验证清单（README 里给出）。
6. 写 README，交付脚本文件。

## 已知限制（会写进 README）

- 上限 3.0x 与 B 站默认长按倍速相同，首次长按从 3.0x 开始按 ↑ 会被上限截断，需先按 ↓（菜单里可改上限）。
- 鼠标右键长按倍速（B 站设置里的"右键长按倍速"）不在本次范围。
- B 站前端改版可能导致选择器失效；脚本选择器集中管理便于更新，菜单里可随时关闭脚本。
