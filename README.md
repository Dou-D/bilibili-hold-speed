# B站 按住方向键倍速微调

一个油猴（用户脚本）插件，给 B 站网页版播放器加上「按住方向键临时变速 + 方向键上下精细调节」的能力。

## 它解决什么问题

B 站原生支持**按住 `→` 长按倍速**（默认 3x），但：

- 倍速是写死的几档（智能 / 1.5x / 2x / 3x），不能精细调节；
- 长按期间按 `↑` / `↓` 在大多数账号上**改的是音量**，而不是倍速；
- 松开后回到长按前倍速（通常是 1x），但如果你原本就是 1.5x 在看，松开还会是 1.5x，不会"复位"。

这个脚本把上面几点补齐：

| 操作 | 效果 |
| --- | --- |
| **按住 `→`**（或 `←`） | 以倍速播放（默认 3x 起步，可用菜单改起始值） |
| 按住期间按 **`↑` / `↓`** | 倍速 +0.25x / −0.25x（步长可调），范围默认 **0.5x ~ 3x** |
| 按住 `↑` / `↓` 不放 | 连续调节（约每 100ms 一档，跨度大时调得快） |
| **松开 `→`** | **立刻回到 1 倍速**——听到重点后松开就恢复正常语速 |
| **短按 `→` / `←`** | 保持 B 站原生的 ±5 秒快进/快退（不做任何改变） |

松开回到 1 倍速是关键设计：看网课时长按加速跳过废话，听到重点直接松手，语速立刻恢复正常，不用再去点倍速菜单。

## 安装

1. 在浏览器里安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey / ScriptCat）。
2. 打开 [bilibili-hold-speed.user.js](./bilibili-hold-speed.user.js)，把全部内容复制到 Tampermonkey 的「新建脚本」编辑器里，`Ctrl+S` 保存。
   - 也可以把 `.user.js` 文件直接拖进浏览器窗口，Tampermonkey 会弹出安装页。
3. 打开任意 B 站视频页，按住 `→` 试试。

> 脚本的作用范围是 `https://www.bilibili.com/*`，普通视频、番剧（`/bangumi/play/`）、课程（`/cheese/play/`）都支持；直播间和首页不会介入。

## 设置

点击 Tampermonkey 图标 → 本脚本的菜单项，可随时调整（改动立即生效并保存）：

| 菜单项 | 可选值 | 默认 |
| --- | --- | --- |
| 长按倍速微调 | 开 / 关 | 开 |
| 触发键 | `←` 和 `→` / 仅 `→` | `←` 和 `→` |
| 起始倍速 | 1 / 1.5 / 2 / 2.5 / 3 | 3 |
| 每档步长 | 0.1 / 0.25 / 0.5 | 0.25 |
| 倍速上限 | 1.5 / 2 / 2.5 / 3 / 4 | 3 |
| 倍速下限 | 0.25 / 0.5 / 0.75 / 1 | 0.5 |
| 松开后恢复 | 1 倍速 / 长按前的倍速 | 1 倍速 |
| 记住上次倍速 | 开 / 关 | 开 |
| 显示倍速浮层 | 开 / 关 | 开 |
| 清除记住的倍速 | — | — |
| 恢复默认设置 | — | — |

几个说明：

- **起始倍速**只在没有记住值时生效（第一次使用，或清除了记忆后）。
- **记住上次倍速**指：你这次把倍速调到 2.5x，下次按住 `→` 就直接从 2.5x 开始，不用每次重新调。它只影响"按住期间"的倍速，不影响松手后的 1x。
- 上限设成 3x 时，如果起始倍速也是 3x，第一次按 `↑` 不会有效果（已经到顶），先按 `↓` 即可。
- 「松开后恢复」设为「长按前的倍速」，行为就变回和 B 站原生一致（适合原本习惯用 1.5x 常速观看的人）。

## 实现要点

- **在 `window` 捕获阶段接管按键**。B 站的播放器快捷键绑在 `window` 冒泡阶段，捕获阶段注册的监听器先执行，因此可以完全压制它的 `→` 长按倍速和 `↑`/`↓` 音量调节，两边不会互相覆盖。
- **`←` / `→` / `↑` / `↓` 全部由脚本自己处理**，包括短按快进（+5s / −5s，与原生一致）和长按倍速，行为完全可预期。
- **在 `<video>` 实例上重定义了 `playbackRate` / `defaultPlaybackRate`**。按住期间任何外部写入（B 站自身逻辑、切换清晰度、其它脚本）都会被纠正回目标倍速，所以不会出现倍速被抢回去或数字跳动。底层通过原型上的原始 setter 写入，避开自身的拦截。
- **切换清晰度 / 切 P 时播放器会替换 `<video>` 元素**：脚本会挑选"真正可见面积最大"的那个元素（切换过程中会短暂插入一个离屏 `<video>`，选错就会把倍速加在看不见的实例上），并在按住期间每 400ms 校对一次。
- **非播放器页面完全 no-op**：只有在 `.bpx-player-container` 等播放器容器内找到合适的 `<video>` 时才接管键盘，首页、直播页等不受影响。
- 输入框聚焦、按住 Ctrl/Shift/Alt、窗口失焦、页面切到后台时都不会触发，或会立即复位。

## 已知限制

- 只能用于网页版，手机 App / 客户端不适用。
- 直播页不生效（B 站直播用的是另一套播放器，且直播本身不支持倍速）。
- **鼠标右键长按倍速**（B 站设置里的同名功能）不受影响，也不会被本脚本接管。
- 脚本依赖 B 站播放器的 DOM 结构（`.bpx-player-container` 等）。B 站前端大改版后可能失效，此时需要更新《实现要点》里用到的选择器（源码中集中在 `TRIGGER_SELECTORS`、`HINT_HOST_SELECTORS` 常量处）；也可以先在菜单里关掉脚本。
- 上限默认 3x 与 B 站默认长按倍速相同；想要更快的扫片速度，可在菜单里把上限调到 4x。

## 开发与测试

```
Speed Adjustment/
├── bilibili-hold-speed.user.js   # 脚本本体（单文件，直接安装）
├── README.md
└── test/
    └── harness.html              # 离线测试台
```

离线测试台复刻了 B 站播放器的 DOM 结构与原生键盘行为（长按 300ms 进入倍速、`↑`/`↓` 调音量、输入框聚焦时跳过），可以在不联网、不依赖 B 站的情况下回归脚本：

```bash
# 在项目目录启动一个静态服务器（任选其一）
npx serve .
python -m http.server 8080
```

然后访问 `http://localhost:8080/test/harness.html`，点「运行全部测试」会跑 18 项断言（进入倍速、上下限夹取、记忆、短按快进、连发节流、输入框、失焦复位、外部写入纠正等）。也可以用键盘手动体验，页面顶部的状态栏会实时显示倍速、音量与脚本状态。

调试时脚本会暴露 `window.__BHS__`（`state` / `cfg` / `resolveVideo()` / `enterMode()` / `exitMode()`），可在浏览器控制台查看。
